01 Requirements & Scope

Functional Requirements
  • 2+ players take turns rolling a standard 6-sided die
  • 100-cell board: players start at position 0 (not on board) and must reach exactly 100
  • Snakes: landing on a snake's head moves you backwards to its tail
  • Ladders: landing on a ladder's bottom moves you forwards to its top
  • Overshoot rule: rolling beyond 100 leaves player in place (no move)
  • Win condition: first player to land exactly on 100 wins; game ends immediately
Variants / Optional Features
  • Multiple dice (sum of two dice per turn)
  • Power-up cells with special effects (freeze, double roll)
  • Safe cells where snake/ladder has no effect
  • Custom board size (not fixed at 100)
  • Undo last turn for debugging or house rules
Clarifying Questions to Ask the Interviewer
Q: Player count range?Bounded? Unlimited? Affects data structures for turn order management.
Q: Board size fixed at 100 or configurable?If configurable, Board constructor takes size parameter.
Q: Overshoot rule — bounce back or stay in place?Classic rules say stay; bounce is a variant. Both are easy to implement differently in applyMove().
Q: Can a snake's head and a ladder's bottom share the same cell?If yes, need precedence rule. Most implementations forbid it.
Q: Turn order fixed (FIFO) or random?Random turn order requires shuffling the players list at game start.
Q: Undo last turn — just one level or full undo history?One level is easy with Command pattern; full history needs a deque.

Dual-use Map: Both snakes and ladders are stored in a single Map<Integer, Integer> jumps. A snake adds jumps.put(head, tail) where tail < head. A ladder adds jumps.put(bottom, top) where top > bottom. board.getDestination(pos) handles both with one getOrDefault() call.

03 Board Design

public class Board {
    private final int size;
    // Unified jump map: key=from, value=to (works for both snakes and ladders)
    private final Map<Integer, Integer> jumps = new HashMap<>();

    public Board(int size) {
        this.size = size;
    }

    /** Add a snake: head must be greater than tail (snake goes DOWN). */
    public void addSnake(int head, int tail) {
        if (head <= tail) {
            throw new IllegalArgumentException(
                "Snake head (" + head + ") must be > tail (" + tail + ")");
        }
        if (!isValidPosition(head) || !isValidPosition(tail)) {
            throw new IllegalArgumentException("Snake positions must be within 1–" + size);
        }
        jumps.put(head, tail);
    }

    /** Add a ladder: bottom must be less than top (ladder goes UP). */
    public void addLadder(int bottom, int top) {
        if (top <= bottom) {
            throw new IllegalArgumentException(
                "Ladder top (" + top + ") must be > bottom (" + bottom + ")");
        }
        if (!isValidPosition(bottom) || !isValidPosition(top)) {
            throw new IllegalArgumentException("Ladder positions must be within 1–" + size);
        }
        if (jumps.containsKey(bottom)) {
            throw new IllegalArgumentException(
                "Cell " + bottom + " already has a snake/ladder.");
        }
        jumps.put(bottom, top);
    }

    /**
     * Given a position a player just landed on, return the final destination.
     * Returns the same position if no snake/ladder is present.
     */
    public int getDestination(int position) {
        return jumps.getOrDefault(position, position);
    }

    public boolean isValidPosition(int pos) {
        return pos >= 1 && pos <= size;
    }

    public int getSize() { return size; }

    public boolean hasSnakeAt(int pos) {
        return jumps.containsKey(pos) && jumps.get(pos) < pos;
    }

    public boolean hasLadderAt(int pos) {
        return jumps.containsKey(pos) && jumps.get(pos) > pos;
    }

    /** Factory: classic 100-cell board with standard snakes and ladders. */
    public static Board createStandardBoard() {
        Board board = new Board(100);
        // Classic snakes
        board.addSnake(99,  5);
        board.addSnake(54, 20);
        board.addSnake(35,  3);
        board.addSnake(70, 55);
        board.addSnake(82, 44);
        // Classic ladders
        board.addLadder( 4, 14);
        board.addLadder( 9, 31);
        board.addLadder(20, 38);
        board.addLadder(26, 60);
        board.addLadder(40, 75);
        board.addLadder(85, 95);
        return board;
    }
}
O(1) lookup: Map<Integer, Integer> for jumps gives O(1) destination lookup — when a player lands on any cell, one getOrDefault() call tells them where to go. No looping through snake/ladder lists, no type-checking required.
Validate at add time: Checking snake head > tail and ladder top > bottom in addSnake() / addLadder() prevents a snake that points up or a ladder that points down — bugs that would manifest silently at runtime and be extremely hard to debug.

04 Player & Movement

public class Player {
    private final String name;
    private int currentPosition; // 0 = not on board yet

    public Player(String name) {
        this.name = name;
        this.currentPosition = 0;
    }

    public String getName()          { return name; }
    public int getCurrentPosition()  { return currentPosition; }
    public boolean isAtStart()       { return currentPosition == 0; }

    /** Raw position update — used by applyMove() and undo(). */
    public void moveTo(int newPosition) {
        this.currentPosition = newPosition;
    }

    /**
     * Apply a dice roll: compute new position, check overshoot, apply board jump.
     * Returns the final position after the move.
     *
     * @param diceRoll number rolled
     * @param board    the game board (for snake/ladder lookup)
     * @return final position after the move
     */
    public int applyMove(int diceRoll, Board board) {
        int rawPosition = currentPosition + diceRoll;

        // Overshoot rule: if beyond winning cell, don't move
        if (rawPosition > board.getSize()) {
            return currentPosition; // stay put
        }

        // Apply board jump (snake or ladder), if any
        int finalPosition = board.getDestination(rawPosition);
        moveTo(finalPosition);
        return finalPosition;
    }
}
Overshoot & Snake Examples
Example 1 — Overshoot (stay in place):
  Player at 97. Rolls 5.
  rawPosition = 97 + 5 = 102.
  102 > 100 → OVERSHOOT → stays at 97. No move recorded.

Example 2 — Exact win:
  Player at 97. Rolls 3.
  rawPosition = 97 + 3 = 100.
  100 == board.size → valid move.
  board.getDestination(100) = 100 (no jump).
  moveTo(100) → 🏆 WINS!

Example 3 — Lands on snake head:
  Player at 95. Rolls 4.
  rawPosition = 95 + 4 = 99.
  board.getDestination(99) = 5  ← snake 99→5
  moveTo(5) → 😱 Moved from 99 back to 5!

Example 4 — Climbs ladder:
  Player at 22. Rolls 4.
  rawPosition = 22 + 4 = 26.
  board.getDestination(26) = 60  ← ladder 26→60
  moveTo(60) → 🪜 Climbed from 26 to 60!

05 Dice (Strategy Pattern)

// ─── Dice interface (Strategy) ───────────────────────────────────────
public interface Dice {
    int roll();
}

// ─── StandardDice ────────────────────────────────────────────────────
public class StandardDice implements Dice {
    private final Random random = new Random();

    @Override
    public int roll() {
        return random.nextInt(6) + 1; // 1–6 inclusive
    }
}

// ─── LoadedDice (for deterministic testing) ──────────────────────────
public class LoadedDice implements Dice {
    private final int[] sequence;
    private int index = 0;

    public LoadedDice(int[] sequence) {
        this.sequence = sequence;
    }

    @Override
    public int roll() {
        if (index >= sequence.length) {
            throw new IllegalStateException("LoadedDice sequence exhausted");
        }
        return sequence[index++];
    }

    public void reset() { index = 0; }
}

// ─── MultiDice (sum of multiple dice per turn) ───────────────────────
public class MultiDice implements Dice {
    private final List<Dice> diceList;

    public MultiDice(List<Dice> diceList) {
        this.diceList = diceList;
    }

    @Override
    public int roll() {
        return diceList.stream().mapToInt(Dice::roll).sum();
    }

    /** Convenience: create n standard dice. */
    public static MultiDice ofStandard(int n) {
        List<Dice> dice = new ArrayList<>();
        for (int i = 0; i < n; i++) dice.add(new StandardDice());
        return new MultiDice(dice);
    }
}
Testability via Strategy: Dice interface makes the game fully deterministic in tests. LoadedDice lets you specify exact roll sequences without randomness.

06 Command Pattern: Turn

Why Command here? Each player's turn is a discrete action with a clear execute and a reversible undo. Wrapping it in a Command object enables: (1) undo last move, (2) full game replay, (3) turn logging with rich metadata.Without Command: undo would require storing previous positions manually scattered across the Game class.
// ─── TurnResult: rich data about what happened this turn ─────────────
public class TurnResult {
    private final Player  player;
    private final int     fromPosition;
    private final int     toPosition;
    private final int     diceRoll;
    private final boolean snakeEncountered;
    private final boolean ladderClimbed;
    private final boolean won;

    public TurnResult(Player player, int from, int to, int roll,
                      boolean snake, boolean ladder, boolean won) {
        this.player           = player;
        this.fromPosition     = from;
        this.toPosition       = to;
        this.diceRoll         = roll;
        this.snakeEncountered = snake;
        this.ladderClimbed    = ladder;
        this.won              = won;
    }

    public Player  getPlayer()          { return player; }
    public int     getFromPosition()    { return fromPosition; }
    public int     getToPosition()      { return toPosition; }
    public int     getDiceRoll()        { return diceRoll; }
    public boolean isSnakeEncountered() { return snakeEncountered; }
    public boolean isLadderClimbed()    { return ladderClimbed; }
    public boolean isWon()              { return won; }
}

// ─── TurnCommand interface ───────────────────────────────────────────
public interface TurnCommand {
    TurnResult execute();
    void undo();
}

// ─── PlayerTurnCommand: concrete command ────────────────────────────
public class PlayerTurnCommand implements TurnCommand {
    private final Player player;
    private final Dice   dice;
    private final Board  board;

    private int prevPosition; // saved for undo
    private int lastRoll;     // saved for result replay

    public PlayerTurnCommand(Player player, Dice dice, Board board) {
        this.player = player;
        this.dice   = dice;
        this.board  = board;
    }

    @Override
    public TurnResult execute() {
        prevPosition = player.getCurrentPosition();
        lastRoll     = dice.roll();

        int rawPos   = prevPosition + lastRoll;
        boolean overshoot = rawPos > board.getSize();
        int finalPos = overshoot ? prevPosition : board.getDestination(rawPos);

        if (!overshoot) {
            player.moveTo(finalPos);
        }

        boolean snakeHit = !overshoot && board.hasSnakeAt(rawPos);
        boolean ladderUp = !overshoot && board.hasLadderAt(rawPos);
        boolean won      = finalPos == board.getSize();

        return new TurnResult(player, prevPosition, finalPos, lastRoll,
                              snakeHit, ladderUp, won);
    }

    @Override
    public void undo() {
        // Restore the player to the position before this turn
        player.moveTo(prevPosition);
    }
}

// ─── CommandHistory: invoker with undo support ───────────────────────
public class CommandHistory {
    private final Deque<TurnCommand> history = new ArrayDeque<>();

    public TurnResult execute(TurnCommand command) {
        TurnResult result = command.execute();
        history.push(command); // push to stack for LIFO undo
        return result;
    }

    public boolean undoLast() {
        if (history.isEmpty()) return false;
        history.pop().undo();
        return true;
    }

    public int size() { return history.size(); }
    public boolean isEmpty() { return history.isEmpty(); }
}
Replay via Command: Store all executed TurnCommands in a list. To replay a game: create fresh Board and Players at position 0, then iterate through all stored commands and call execute() again — every game state is reconstructible. Useful for spectators, highlight reels, or post-game analysis.

07 Observer Pattern: Game Events

// ─── GameObserver interface ──────────────────────────────────────────
public interface GameObserver {
    void onPlayerMoved(Player player, int from, int to, int diceRoll);
    void onSnakeEncountered(Player player, int landedAt, int slidTo);
    void onLadderClimbed(Player player, int landedAt, int climbedTo);
    void onPlayerWon(Player player, int totalTurns);
    void onOvershoot(Player player, int currentPos, int roll);
}

// ─── ConsoleLogger: pretty-prints events to stdout ───────────────────
public class ConsoleLogger implements GameObserver {

    @Override
    public void onPlayerMoved(Player p, int from, int to, int roll) {
        System.out.printf("🎲  %-10s rolled %d  |  %3d → %3d%n",
                          p.getName(), roll, from, to);
    }

    @Override
    public void onSnakeEncountered(Player p, int landedAt, int slidTo) {
        System.out.printf("🐍  %s hit a SNAKE at %d → slides down to %d!%n",
                          p.getName(), landedAt, slidTo);
    }

    @Override
    public void onLadderClimbed(Player p, int landedAt, int climbedTo) {
        System.out.printf("🪜  %s found a LADDER at %d → climbs up to %d!%n",
                          p.getName(), landedAt, climbedTo);
    }

    @Override
    public void onPlayerWon(Player p, int totalTurns) {
        System.out.printf("🏆  %s WINS in %d turns! Congratulations!%n",
                          p.getName(), totalTurns);
    }

    @Override
    public void onOvershoot(Player p, int currentPos, int roll) {
        System.out.printf("⛔  %s at %d rolled %d → overshoots! Stays at %d.%n",
                          p.getName(), currentPos, roll, currentPos);
    }
}

// ─── ScoreTracker: gathers statistics per player ─────────────────────
public class ScoreTracker implements GameObserver {
    private final Map<String, Integer> turnsCount   = new HashMap<>();
    private final Map<String, Integer> snakesHit    = new HashMap<>();
    private final Map<String, Integer> laddersFound = new HashMap<>();

    @Override
    public void onPlayerMoved(Player p, int from, int to, int roll) {
        turnsCount.merge(p.getName(), 1, Integer::sum);
    }

    @Override
    public void onSnakeEncountered(Player p, int at, int to) {
        snakesHit.merge(p.getName(), 1, Integer::sum);
    }

    @Override
    public void onLadderClimbed(Player p, int at, int to) {
        laddersFound.merge(p.getName(), 1, Integer::sum);
    }

    @Override
    public void onPlayerWon(Player p, int totalTurns) {
        System.out.println("=== GAME STATS ===");
        turnsCount.forEach((name, turns) ->
            System.out.printf("  %-10s : %2d turns, %d snakes, %d ladders%n",
                name, turns,
                snakesHit.getOrDefault(name, 0),
                laddersFound.getOrDefault(name, 0)));
    }

    @Override
    public void onOvershoot(Player p, int pos, int roll) {
        // Not tracked in stats; ignored here
    }

    public int getTurns(String playerName) {
        return turnsCount.getOrDefault(playerName, 0);
    }
}
Zero coupling: The Game class calls notifySnakeEncountered(player, from, to) — it doesn't know whether a ConsoleLogger, an AnimationController, or a NetworkBroadcaster is listening. Adding WebSocket broadcast for a multiplayer UI means implementing GameObserver once, zero changes to Game.

08 Game Loop

public class Game {
    private final Board               board;
    private final List<Player>        players         = new ArrayList<>();
    private final List<GameObserver>  observers       = new ArrayList<>();
    private final CommandHistory      commandHistory  = new CommandHistory();
    private Dice                      dice;
    private int                       currentPlayerIndex = 0;
    private boolean                   gameOver        = false;

    public Game(Board board, Dice dice) {
        this.board = board;
        this.dice  = dice;
    }

    // ── Configuration ────────────────────────────────────────────────
    public void addPlayer(Player player)         { players.add(player); }
    public void addObserver(GameObserver observer){ observers.add(observer); }
    public void setDice(Dice dice)               { this.dice = dice; }

    // ── Main game loop ────────────────────────────────────────────────
    public void start() {
        if (players.size() < 2) {
            throw new IllegalStateException("Need at least 2 players to start.");
        }
        gameOver = false;
        currentPlayerIndex = 0;
        while (!gameOver) {
            playTurn();
        }
    }

    public void playTurn() {
        if (gameOver) return;

        Player player = players.get(currentPlayerIndex);
        TurnCommand cmd = new PlayerTurnCommand(player, dice, board);
        TurnResult result = commandHistory.execute(cmd);

        // ── Notify observers ─────────────────────────────────────────
        if (result.getFromPosition() == result.getToPosition()
                && result.getDiceRoll() + result.getFromPosition() > board.getSize()) {
            // Overshoot
            notifyOvershoot(player, result.getFromPosition(), result.getDiceRoll());
        } else {
            notifyMoved(player, result.getFromPosition(), result.getToPosition(), result.getDiceRoll());
            if (result.isSnakeEncountered()) {
                int landedAt = result.getFromPosition() + result.getDiceRoll();
                notifySnake(player, landedAt, result.getToPosition());
            }
            if (result.isLadderClimbed()) {
                int landedAt = result.getFromPosition() + result.getDiceRoll();
                notifyLadder(player, landedAt, result.getToPosition());
            }
        }

        if (result.isWon()) {
            gameOver = true;
            notifyWon(player, commandHistory.size());
        } else {
            // Advance to next player (circular)
            currentPlayerIndex = (currentPlayerIndex + 1) % players.size();
        }
    }

    /** Undo the last turn (house rule / debugging). */
    public boolean undoLastTurn() {
        if (!commandHistory.undoLast()) return false;
        // Roll back the turn index
        currentPlayerIndex = (currentPlayerIndex - 1 + players.size()) % players.size();
        return true;
    }

    // ── Observer notification helpers ─────────────────────────────────
    private void notifyMoved(Player p, int from, int to, int roll) {
        observers.forEach(o -> o.onPlayerMoved(p, from, to, roll));
    }
    private void notifySnake(Player p, int from, int to) {
        observers.forEach(o -> o.onSnakeEncountered(p, from, to));
    }
    private void notifyLadder(Player p, int from, int to) {
        observers.forEach(o -> o.onLadderClimbed(p, from, to));
    }
    private void notifyWon(Player p, int turns) {
        observers.forEach(o -> o.onPlayerWon(p, turns));
    }
    private void notifyOvershoot(Player p, int pos, int roll) {
        observers.forEach(o -> o.onOvershoot(p, pos, roll));
    }

    public boolean isGameOver()        { return gameOver; }
    public Board   getBoard()          { return board; }
    public Player  getCurrentPlayer()  { return players.get(currentPlayerIndex); }
}
Single Responsibility: Game orchestrates — it doesn't contain game logic (that's in Board and Player), doesn't track stats (that's in ScoreTracker), and doesn't print (that's in ConsoleLogger). It just drives the loop and fires events.

// Cell effect strategy
public interface CellEffect {
    void apply(Player player, Game game);
    String describe();
}

public class FreezeEffect implements CellEffect {
    @Override
    public void apply(Player player, Game game) {
        game.skipNextTurnFor(player); // Game tracks skip-set
    }
    @Override public String describe() { return "FROZEN — skip next turn"; }
}

public class DoubleRollEffect implements CellEffect {
    @Override
    public void apply(Player player, Game game) {
        game.grantBonusRoll(player); // Game sets bonus flag
    }
    @Override public String describe() { return "BONUS — roll again!"; }
}

// Board stores effects separately from jumps
public class Board {
    private final Map<Integer, CellEffect> effects = new HashMap<>();

    public void addEffect(int position, CellEffect effect) {
        effects.put(position, effect);
    }

    public Optional<CellEffect> getEffect(int position) {
        return Optional.ofNullable(effects.get(position));
    }
}

Undo with Timeout
Timed undo: Store a timestamp in TurnResult. In Game.undoLastTurn(), check if the last turn was within 5 seconds (Duration.between(lastTurn.getTimestamp(), Instant.now()).getSeconds() <= 5). Reject undo if too late.Prevents players from using undo as a cheat after seeing a snake result.
Multiplayer Web (State Serialization)
GameState POJO: Game.getState() returns a GameState with: List of PlayerState (name, position), currentPlayer, gameOver flag, boardSize. Serialize to JSON via Jackson. WebSocket server broadcasts GameState after each turn to all connected clients.This is also the foundation for game replay: store GameState after each turn.
AI Player
public class AIPlayer extends Player {
    public AIPlayer(String name) { super(name); }

    /**
     * Simple AI: just rolls and moves (same as human).
     * Advanced AI could use simulation to pick best move among multiple dice options.
     */
    public TurnResult takeTurn(Dice dice, Board board) {
        int roll = dice.roll();
        int finalPos = applyMove(roll, board);
        boolean won = finalPos == board.getSize();
        return new TurnResult(this, getCurrentPosition(), finalPos, roll,
                              board.hasSnakeAt(getCurrentPosition() + roll),
                              board.hasLadderAt(getCurrentPosition() + roll),
                              won);
    }
}

// Game loop checks type and auto-plays AI turns without waiting for input:
if (player instanceof AIPlayer) {
    // Play immediately without waiting for user input
    playTurn();
}

11 Interview Talking Points

On Board jump lookup: "Map<Integer, Integer> for jumps is O(1) lookup — cleaner than a Cell[] array where you'd have to check a type field, and cheaper than keeping separate snake and ladder lists that you'd have to search. A single getOrDefault() call tells a player where to land."
On Command Pattern: "Command enables both undo and replay. TurnCommand.undo() restores the player's previous position in one line — no scattered state management in Game. CommandHistory stores all commands, so you can re-execute them on a fresh board to reconstruct any historical game state for spectators or post-game analysis."
On Observer Pattern: "Observer completely decouples game logic from output concerns. Adding animated UI or network broadcast means implementing GameObserver — zero changes to the Game class. The game doesn't know whether it's running in a console, a GUI, or a distributed multiplayer server."
On Dice Strategy (testability): "Dice interface makes the game deterministic in tests. LoadedDice with a fixed sequence lets me verify exact win conditions, overshoot behavior, and snake encounters without any randomness. I can write: 'assert player wins after exactly 8 turns' with complete confidence."
On the overshoot boundary condition: "Overshoot is the most commonly missed edge case. Player at 97 rolls 5 → 102 > 100 → stays at 97. It's a one-liner in applyMove() but easy to forget without an explicit test. I'd write a dedicated unit test: LoadedDice(97) → player starts at 97, rolls 5, assert position still 97."
