01 Requirements & Scope

Functional Requirements

  • Support N elevators and M floors (configured at startup).
  • Internal requests: passenger inside cabin presses a destination floor button.
  • External requests: passenger on a floor presses UP or DOWN on the hall panel.
  • Elevators have three core states: Idle, MovingUp, MovingDown.
  • Door opens automatically on arrival; closes after a configurable dwell time.
  • Display inside and outside shows current floor and direction.

Non-Functional Requirements

  • Concurrent button presses: multiple people press buttons simultaneously — no race conditions.
  • Optimal dispatch: best elevator is selected based on scheduling strategy.
  • Extensible strategy: swap scheduling algorithm without changing elevator logic.
  • Starvation-free: no floor should wait indefinitely.

03 State Pattern: Elevator States

Design Insight: State pattern prevents door-open-while-moving bugs at the design level, not just runtime checks. Each state object knows exactly which transitions are legal.

Direction Enum

public enum Direction {
    UP, DOWN
}

ElevatorState Interface

public interface ElevatorState {
    void moveUp(Elevator elevator);
    void moveDown(Elevator elevator);
    void openDoor(Elevator elevator);
    void closeDoor(Elevator elevator);
    void addRequest(Elevator elevator, int floor);
    String getStateName();
}

IdleState

public class IdleState implements ElevatorState {

    @Override
    public void moveUp(Elevator elevator) {
        System.out.println("Elevator " + elevator.getElevatorId() + " starting UP from floor " + elevator.getCurrentFloor());
        elevator.setState(new MovingUpState());
        elevator.setDirection(Direction.UP);
    }

    @Override
    public void moveDown(Elevator elevator) {
        System.out.println("Elevator " + elevator.getElevatorId() + " starting DOWN from floor " + elevator.getCurrentFloor());
        elevator.setState(new MovingDownState());
        elevator.setDirection(Direction.DOWN);
    }

    @Override
    public void openDoor(Elevator elevator) {
        // Idle at a floor — safe to open
        elevator.getDoor().open();
        System.out.println("Elevator " + elevator.getElevatorId() + " door OPEN at floor " + elevator.getCurrentFloor());
    }

    @Override
    public void closeDoor(Elevator elevator) {
        elevator.getDoor().close();
    }

    @Override
    public void addRequest(Elevator elevator, int floor) {
        if (floor > elevator.getCurrentFloor()) {
            elevator.getUpQueue().offer(floor);
            moveUp(elevator);
        } else if (floor < elevator.getCurrentFloor()) {
            elevator.getDownQueue().offer(floor);
            moveDown(elevator);
        } else {
            // Already here — just open the door
            openDoor(elevator);
        }
    }

    @Override
    public String getStateName() { return "IDLE"; }
}

MovingUpState

public class MovingUpState implements ElevatorState {

    @Override
    public void moveUp(Elevator elevator) {
        // Already moving up — no-op, just continue
        System.out.println("Elevator " + elevator.getElevatorId() + " already moving UP");
    }

    @Override
    public void moveDown(Elevator elevator) {
        // Switch direction only when upQueue is exhausted
        if (elevator.getUpQueue().isEmpty()) {
            elevator.setState(new MovingDownState());
            elevator.setDirection(Direction.DOWN);
        } else {
            System.out.println("Cannot switch direction — upQueue still has " + elevator.getUpQueue().size() + " stops");
        }
    }

    @Override
    public void openDoor(Elevator elevator) {
        throw new IllegalStateException(
            "Cannot open door while elevator " + elevator.getElevatorId() + " is moving UP. Current floor: " + elevator.getCurrentFloor()
        );
    }

    @Override
    public void closeDoor(Elevator elevator) {
        // Door should already be closed while moving
    }

    @Override
    public void addRequest(Elevator elevator, int floor) {
        elevator.getLock().lock();
        try {
            if (floor > elevator.getCurrentFloor()) {
                // Same direction — add to upQueue (min-heap, so it's picked up on the way)
                elevator.getUpQueue().offer(floor);
                System.out.println("Floor " + floor + " added to upQueue of elevator " + elevator.getElevatorId());
            } else {
                // Opposite direction — add to downQueue to serve on return sweep
                elevator.getDownQueue().offer(floor);
                System.out.println("Floor " + floor + " added to downQueue (opposite direction) of elevator " + elevator.getElevatorId());
            }
        } finally {
            elevator.getLock().unlock();
        }
    }

    @Override
    public String getStateName() { return "MOVING_UP"; }
}

MovingDownState

public class MovingDownState implements ElevatorState {

    @Override
    public void moveDown(Elevator elevator) {
        System.out.println("Elevator " + elevator.getElevatorId() + " already moving DOWN");
    }

    @Override
    public void moveUp(Elevator elevator) {
        if (elevator.getDownQueue().isEmpty()) {
            elevator.setState(new MovingUpState());
            elevator.setDirection(Direction.UP);
        } else {
            System.out.println("Cannot switch direction — downQueue still has " + elevator.getDownQueue().size() + " stops");
        }
    }

    @Override
    public void openDoor(Elevator elevator) {
        throw new IllegalStateException(
            "Cannot open door while elevator " + elevator.getElevatorId() + " is moving DOWN. Current floor: " + elevator.getCurrentFloor()
        );
    }

    @Override
    public void closeDoor(Elevator elevator) {
        // Already closed while moving
    }

    @Override
    public void addRequest(Elevator elevator, int floor) {
        elevator.getLock().lock();
        try {
            if (floor < elevator.getCurrentFloor()) {
                // Same direction — add to downQueue (max-heap)
                elevator.getDownQueue().offer(floor);
                System.out.println("Floor " + floor + " added to downQueue of elevator " + elevator.getElevatorId());
            } else {
                // Opposite direction — add to upQueue
                elevator.getUpQueue().offer(floor);
                System.out.println("Floor " + floor + " added to upQueue (opposite direction) of elevator " + elevator.getElevatorId());
            }
        } finally {
            elevator.getLock().unlock();
        }
    }

    @Override
    public String getStateName() { return "MOVING_DOWN"; }
}
Anti-pattern: If you use if-else in Elevator.openDoor() to check direction, you will forget a state and create a runtime bug. The State pattern makes illegal transitions structurally impossible — MovingUpState.openDoor() throws at design time.

04 Elevator Class

The Elevator class is the stateful actor. It delegates all behaviour to the current ElevatorState and uses a ReentrantLock to protect queue mutations from concurrent threads.

import java.util.PriorityQueue;
import java.util.Collections;
import java.util.concurrent.locks.ReentrantLock;

public class Elevator {

    private final int elevatorId;
    private int currentFloor;
    private Direction direction;
    private ElevatorState currentState;

    // Min-heap: smallest floor number first (ascending sweep)
    private final PriorityQueue<Integer> upQueue;
    // Max-heap: largest floor number first (descending sweep)
    private final PriorityQueue<Integer> downQueue;

    private final Door door;
    private final Display display;
    private final ReentrantLock lock;

    private final int capacity;
    private int currentOccupancy;

    public Elevator(int elevatorId, int startFloor, int capacity) {
        this.elevatorId = elevatorId;
        this.currentFloor = startFloor;
        this.capacity = capacity;
        this.currentOccupancy = 0;
        this.direction = null;
        this.currentState = new IdleState();
        this.upQueue = new PriorityQueue<>();                        // natural order
        this.downQueue = new PriorityQueue<>(Collections.reverseOrder()); // reverse order
        this.door = new Door(elevatorId);
        this.display = new Display(elevatorId);
        this.lock = new ReentrantLock();
    }

    /** Called by state objects or controller to add a floor stop */
    public void addRequest(int floor) {
        currentState.addRequest(this, floor);
    }

    /** Advance one floor toward next destination */
    public void move() {
        lock.lock();
        try {
            if (currentState instanceof MovingUpState && !upQueue.isEmpty()) {
                currentFloor++;
                display.showFloor(currentFloor);
                display.showDirection(Direction.UP);
                System.out.println("[E" + elevatorId + "] Moving UP → floor " + currentFloor);

                if (upQueue.peek() == currentFloor) {
                    upQueue.poll();
                    stop();
                }
            } else if (currentState instanceof MovingDownState && !downQueue.isEmpty()) {
                currentFloor--;
                display.showFloor(currentFloor);
                display.showDirection(Direction.DOWN);
                System.out.println("[E" + elevatorId + "] Moving DOWN → floor " + currentFloor);

                if (downQueue.peek() == currentFloor) {
                    downQueue.poll();
                    stop();
                }
            } else {
                // Nothing left to serve — go idle
                currentState = new IdleState();
                direction = null;
                display.showDirection(null);
                System.out.println("[E" + elevatorId + "] Now IDLE at floor " + currentFloor);
            }
        } finally {
            lock.unlock();
        }
    }

    /** Arrival at a floor: open door, wait, close */
    public void stop() {
        System.out.println("[E" + elevatorId + "] Stopped at floor " + currentFloor);
        door.open();
        try { Thread.sleep(3000); } catch (InterruptedException e) { Thread.currentThread().interrupt(); }
        door.close();

        // After servicing this stop, check if more work to do
        if (!upQueue.isEmpty() && direction == Direction.UP) {
            currentState = new MovingUpState();
        } else if (!downQueue.isEmpty() && direction == Direction.DOWN) {
            currentState = new MovingDownState();
        } else if (!downQueue.isEmpty()) {
            currentState = new MovingDownState();
            direction = Direction.DOWN;
        } else if (!upQueue.isEmpty()) {
            currentState = new MovingUpState();
            direction = Direction.UP;
        } else {
            currentState = new IdleState();
            direction = null;
        }
    }

    public void openDoor()  { currentState.openDoor(this); }
    public void closeDoor() { currentState.closeDoor(this); }

    // ── Getters & Setters ──────────────────────────────────────────────────────
    public int getElevatorId()             { return elevatorId; }
    public int getCurrentFloor()           { return currentFloor; }
    public Direction getDirection()        { return direction; }
    public void setDirection(Direction d)  { this.direction = d; }
    public ElevatorState getCurrentState() { return currentState; }
    public void setState(ElevatorState s)  { this.currentState = s; }
    public PriorityQueue<Integer> getUpQueue()   { return upQueue; }
    public PriorityQueue<Integer> getDownQueue()  { return downQueue; }
    public Door getDoor()                  { return door; }
    public Display getDisplay()            { return display; }
    public ReentrantLock getLock()         { return lock; }
    public boolean isIdle()               { return currentState instanceof IdleState; }
    public boolean isFull()               { return currentOccupancy >= capacity; }
    public void board()   { if (!isFull()) currentOccupancy++; }
    public void alight()  { if (currentOccupancy > 0) currentOccupancy--; }
}

05 Strategy Pattern: Scheduling

ElevatorSchedulingStrategy Interface

public interface ElevatorSchedulingStrategy {
    /**
     * Select the best elevator to serve an external request.
     * @param elevators  all available elevators
     * @param request    the external hall-button request
     * @return           selected Elevator (never null)
     */
    Elevator selectElevator(List<Elevator> elevators, ExternalRequest request);
}

NearestElevatorStrategy — O(n) scan, simple scoring

public class NearestElevatorStrategy implements ElevatorSchedulingStrategy {

    private static final int MOVING_PENALTY = 3; // floors of extra cost for a busy elevator

    @Override
    public Elevator selectElevator(List<Elevator> elevators, ExternalRequest request) {
        Elevator best = null;
        int bestScore = Integer.MAX_VALUE;

        for (Elevator e : elevators) {
            int distance = Math.abs(e.getCurrentFloor() - request.getFloor());
            int score = distance + (e.isIdle() ? 0 : MOVING_PENALTY);
            if (score < bestScore) {
                bestScore = score;
                best = e;
            }
        }
        return best;
    }
}

ScanStrategy — LOOK algorithm, direction-aware

public class ScanStrategy implements ElevatorSchedulingStrategy {

    @Override
    public Elevator selectElevator(List<Elevator> elevators, ExternalRequest request) {
        int requestFloor = request.getFloor();
        Direction requestDir = request.getDirection();

        Elevator bestSameDir = null;
        int bestSameDirDist = Integer.MAX_VALUE;

        Elevator bestIdle = null;
        int bestIdleDist = Integer.MAX_VALUE;

        Elevator bestAny = null;
        int bestAnyDist = Integer.MAX_VALUE;

        for (Elevator e : elevators) {
            int dist = Math.abs(e.getCurrentFloor() - requestFloor);

            // Elevator already on same-direction path and hasn't passed the request floor
            boolean sameDir = (e.getDirection() == requestDir);
            boolean enRoute = (requestDir == Direction.UP   && e.getCurrentFloor() <= requestFloor)
                           || (requestDir == Direction.DOWN && e.getCurrentFloor() >= requestFloor);

            if (sameDir && enRoute && dist < bestSameDirDist) {
                bestSameDirDist = dist;
                bestSameDir = e;
            }
            if (e.isIdle() && dist < bestIdleDist) {
                bestIdleDist = dist;
                bestIdle = e;
            }
            if (dist < bestAnyDist) {
                bestAnyDist = dist;
                bestAny = e;
            }
        }

        // Priority: same-direction en-route > nearest idle > nearest any
        if (bestSameDir != null) return bestSameDir;
        if (bestIdle    != null) return bestIdle;
        return bestAny;
    }
}
Strategy swap at runtime: controller.setStrategy(new ScanStrategy()) during peak hours, revert to NearestElevatorStrategy at night — zero restart, zero code change in Elevator.

06 ElevatorController Class

import java.util.*;
import java.util.concurrent.ConcurrentHashMap;

public class ElevatorController {

    private final List<Elevator> elevators;
    private volatile ElevatorSchedulingStrategy strategy;

    // Tracks unserviced external requests per floor for retry on elevator failure
    private final Map<Integer, List<ExternalRequest>> pendingExternalRequests
        = new ConcurrentHashMap<>();

    public ElevatorController(List<Elevator> elevators, ElevatorSchedulingStrategy strategy) {
        this.elevators = Collections.unmodifiableList(elevators);
        this.strategy  = strategy;
    }

    /**
     * Called when a hall-button (UP/DOWN) is pressed on a floor.
     */
    public void handleExternalRequest(int floor, Direction direction) {
        ExternalRequest req = new ExternalRequest(floor, direction);

        // Park this request so we can retry if selected elevator fails
        pendingExternalRequests
            .computeIfAbsent(floor, k -> Collections.synchronizedList(new ArrayList<>()))
            .add(req);

        Elevator selected = strategy.selectElevator(elevators, req);
        System.out.println("[Controller] External request (floor=" + floor + ", dir=" + direction
            + ") → assigned to Elevator " + selected.getElevatorId());

        selected.addRequest(floor);

        // Remove from pending once dispatched
        pendingExternalRequests.getOrDefault(floor, Collections.emptyList()).remove(req);
    }

    /**
     * Called when a cabin-button is pressed inside an elevator.
     */
    public void handleInternalRequest(int elevatorId, int destinationFloor) {
        Elevator target = findById(elevatorId);
        if (target == null) throw new IllegalArgumentException("No elevator with id " + elevatorId);

        System.out.println("[Controller] Internal request (elevatorId=" + elevatorId
            + ", dest=" + destinationFloor + ")");
        target.addRequest(destinationFloor);
    }

    /**
     * Hot-swap the scheduling algorithm — no restart required.
     */
    public void setStrategy(ElevatorSchedulingStrategy strategy) {
        this.strategy = strategy;
        System.out.println("[Controller] Scheduling strategy switched to: "
            + strategy.getClass().getSimpleName());
    }

    public List<Elevator> getElevators() { return elevators; }

    private Elevator findById(int id) {
        return elevators.stream().filter(e -> e.getElevatorId() == id).findFirst().orElse(null);
    }
}

Why Direction Matters for Scheduling

When an elevator is moving UP and passes floor 4, it should pick up a passenger on floor 4 pressing UP (same direction), but not one pressing DOWN — that passenger will be served on the return sweep. ScanStrategy exploits this to avoid unnecessary stops and direction reversals.

// Inside ScanStrategy — illustrates direction-aware pickup decision:
boolean shouldPickUp = (e.getDirection() == request.getDirection())      // same direction
                     && (request.getDirection() == Direction.UP
                             ? e.getCurrentFloor() <= request.getFloor()   // haven't passed yet
                             : e.getCurrentFloor() >= request.getFloor());
Key insight: Without ExternalRequest carrying direction, the scheduler cannot distinguish a UP request from a DOWN request on the same floor. An elevator would make an unnecessary stop, open the door, and then the passenger wouldn't board because it's going the wrong way — wasting 3 seconds dwell time per floor.

08 Concurrency Deep Dive

Race Condition 1: Duplicate Dispatch

Two people on floors 2 and 9 simultaneously press floor 7's UP button. Both threads call handleExternalRequest(7, UP). Without synchronisation, both could evaluate the strategy and assign two different elevators to floor 7 — double service, wasted trip.

Fix: Synchronise handleExternalRequest or use a ConcurrentHashMap to deduplicate pending external requests before dispatch.

Race Condition 2: PriorityQueue Corruption

Elevator is moving UP processing its upQueue. Simultaneously, a new request comes in on another thread and calls upQueue.offer(). PriorityQueue is not thread-safe — concurrent structural modification can corrupt the heap invariant, causing wrong floor selections.

Fix: Wrap all queue reads and writes inside ReentrantLock.

// Thread-safe addRequest inside Elevator (called by state objects)
public void threadSafeAddRequest(int floor) {
    lock.lock();
    try {
        currentState.addRequest(this, floor);
    } finally {
        lock.unlock();
    }
}

// tryLock variant — non-blocking with retry
public boolean tryAddRequest(int floor) {
    try {
        if (lock.tryLock(50, java.util.concurrent.TimeUnit.MILLISECONDS)) {
            try {
                currentState.addRequest(this, floor);
                return true;
            } finally {
                lock.unlock();
            }
        } else {
            System.out.println("[E" + elevatorId + "] Lock contention — request for floor "
                + floor + " queued for retry");
            return false;
        }
    } catch (InterruptedException e) {
        Thread.currentThread().interrupt();
        return false;
    }
}

Race Condition 3: State Transition While Moving

Elevator thread calls move() and reads currentState. Controller thread simultaneously calls setState(new IdleState()). Without visibility guarantee, the elevator thread sees the old state.

Fix: Declare currentState as volatile, or use the same ReentrantLock for both read and write.

// In Elevator — volatile ensures state changes are visible across threads
private volatile ElevatorState currentState;
Why ReentrantLock over synchronized: tryLock(50, MILLISECONDS) lets us detect lock contention and retry or route the request to another elevator. With synchronized, the thread blocks indefinitely — no timeout possible.

09 SCAN Algorithm (Disk Scheduling Analogy)

Mental model: Exactly like disk head scheduling — the elevator sweeps in one direction serving all queued floors, then reverses. This gives bounded wait time: a floor 1 passenger will be served after at most one full up-sweep, not repeatedly bypassed as floors 5–10 keep requesting.

Data Structures

QueueTypeHeap PropertyPurpose
upQueuePriorityQueue<Integer>Min-heap (lowest first)Serve floors in ascending order on UP sweep
downQueuePriorityQueue<Integer>(reverseOrder)Max-heap (highest first)Serve floors in descending order on DOWN sweep

Complexity

OperationSCANNearestCar
Add requestO(log n) — heap insertO(n) — linear scan
Get next floorO(1) — peek top of heapO(n) — rescan all requests
Worst-case waitBounded — 2 × floor_rangeUnbounded — starvation possible
FairnessHigh — FIFO within directionLow — near floors always win

SCAN Move Loop (simplified)

public void runScan() {
    while (true) {
        // ── Phase 1: sweep UP ──────────────────────────────────────────────────
        while (!upQueue.isEmpty()) {
            int nextStop = upQueue.peek(); // smallest floor above us
            while (currentFloor < nextStop) {
                currentFloor++;
                display.showFloor(currentFloor);
            }
            upQueue.poll();
            stop(); // open door, dwell, close
        }

        // ── Phase 2: sweep DOWN ────────────────────────────────────────────────
        while (!downQueue.isEmpty()) {
            int nextStop = downQueue.peek(); // largest floor below us
            while (currentFloor > nextStop) {
                currentFloor--;
                display.showFloor(currentFloor);
            }
            downQueue.poll();
            stop();
        }

        // ── Both empty: go idle ────────────────────────────────────────────────
        if (upQueue.isEmpty() && downQueue.isEmpty()) {
            setState(new IdleState());
            break;
        }
    }
}
LOOK vs SCAN: Classic SCAN goes all the way to the top/bottom floor even if no requests exist there. LOOK reverses as soon as the highest/lowest pending request is served. The implementation above is LOOK (uses peek() as turnaround point), which is more efficient in practice.

  3. E2.addRequest(3) → lock acquired. IdleState sees queue empty, floor 3 > currentFloor 2. upQueue=[3]. Calls moveUp() → setState(MovingUpState). Lock released.
  4. E2 starts moving: floor 2 → 3. Display shows "Floor 3 | ↑". upQueue.peek()=3, currentFloor=3. Match → upQueue.poll(). stop() called.
  5. E2 arrives floor 3: Door opens. Person boards. board() → occupancy=1. 3-second dwell.
  6. Person inside presses floor 8.
    ElevatorController.handleInternalRequest(elevatorId=2, floor=8)
    E2.addRequest(8) → MovingUpState: 8 > currentFloor(3) → upQueue=[8].
  7. Door closes. E2 resumes: state=MovingUpState. Sweeps: 3→4→5→6→7→8.
  8. Arrives floor 8. upQueue.peek()=8, match → poll. stop() → Door opens. Person alights. occupancy=0.
  9. upQueue empty, downQueue empty → setState(IdleState). E2 now Idle at floor 8.
  10. Meanwhile E3 was serving floor 3 on its downward sweep. Arrives floor 3, serves whoever is there (if any remaining DOWN-direction passengers). downQueue=[] → E3 goes Idle at floor 3.

t=0  [E2:F2 Idle]   ─── request(3,UP) assigned ──────────────────
t=1  [E2:F3 MovUp]  ─── arrived, door OPEN, person boards ───────
t=4  [E2:F3 MovUp]  ─── door CLOSED, request(8) added ───────────

Emergency / Fire Mode

public class EmergencyState implements ElevatorState {
    @Override public void moveDown(Elevator e) {
        // Force to floor 1 regardless of queue
        while (e.getCurrentFloor() > 1) {
            e.setCurrentFloor(e.getCurrentFloor() - 1);
        }
        e.getDoor().open(); // Hold open
    }
    @Override public void addRequest(Elevator e, int floor) {
        System.out.println("EMERGENCY MODE — all requests ignored");
    }
    @Override public void moveUp(Elevator e)  { /* blocked */ }
    @Override public void openDoor(Elevator e){ e.getDoor().open(); }
    @Override public void closeDoor(Elevator e){ /* blocked */ }
    @Override public String getStateName()   { return "EMERGENCY"; }
}

// Triggered via controller:
public void triggerEmergency() {
    elevators.forEach(e -> e.setState(new EmergencyState()));
    elevators.forEach(e -> e.getCurrentState().moveDown(e));
}

VIP Floor Filter

public class VIPElevatorFilter implements ElevatorSchedulingStrategy {
    private final ElevatorSchedulingStrategy delegate;
    private final Set<Integer> vipElevatorIds;

    public VIPElevatorFilter(ElevatorSchedulingStrategy delegate, Set<Integer> vipIds) {
        this.delegate = delegate;
        this.vipElevatorIds = vipIds;
    }

    @Override
    public Elevator selectElevator(List<Elevator> elevators, ExternalRequest request) {
        boolean isVipFloor = request.getFloor() >= 50; // floors 50+ are VIP
        List<Elevator> pool = isVipFloor
            ? elevators.stream().filter(e -> vipElevatorIds.contains(e.getElevatorId())).toList()
            : elevators.stream().filter(e -> !vipElevatorIds.contains(e.getElevatorId())).toList();
        return delegate.selectElevator(pool.isEmpty() ? elevators : pool, request);
    }
}

12 Interview Talking Points

1. ReentrantLock vs synchronized "I use ReentrantLock because tryLock(50ms) lets me handle contention gracefully — if a queue can't be locked, I can retry or route to a different elevator. synchronized blocks the thread indefinitely with no fallback." 2. PriorityQueue choice "Min-heap for upQueue gives O(log n) insertion and O(1) peek to the next floor above us. Compared to a sorted list, we avoid O(n) re-sort after every insertion." 3. State pattern value "MovingUpState.openDoor() throws IllegalStateException — door-open-while-moving is impossible by construction, not just by defensive if-checks. The design enforces correctness." 4. SCAN vs NearestCar "NearestCar can starve floor 1 in a high-traffic building where floors 5–10 constantly request. SCAN guarantees bounded wait: at most 2×floor_range ticks before any floor is served." 5. Strategy hot-swap "setStrategy() on ElevatorController swaps the algorithm at runtime — NearestCar during off-peak, SCAN during rush hour — with no service interruption and no change to Elevator code. Open/Closed in practice." 6. Volatile state field "currentState is volatile because the elevator's run loop and the controller's dispatch thread both read/write it. Without volatile, the JVM may cache the old state in a register and the run loop never sees the EmergencyState update."
Bonus depth: Mention that in a real distributed system, each elevator would have its own microservice with a message queue (Kafka/SQS) as the request bus. The ElevatorController becomes a consumer group. State is persisted in Redis for fault tolerance.
